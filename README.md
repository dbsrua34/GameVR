# Labyrinth Gear

## 1. 게임 개요

| 항목 | 내용 |
| :--- | :--- |
| **게임 제목** | Labyrinth Gear |
| **장르** | Top-down / Puzzle / Action |
| **개발 엔진** | Unreal Engine 5.4.4 |
| **플랫폼** | PC |
| **플레이 방식** | Single Player |
| **시점** | Top-down (쿼터뷰) |
| **예상 플레이 시간** | 5~10분 |

### 한 줄 소개
> 기계 장치로 가득한 미로 방에서 톱니바퀴와 열쇠를 수집해 막힌 길을 열고 제한 시간 내에 탈출하는 탑다운 퍼즐 액션 게임

---

## 2. 게임 컨셉

플레이어는 거대한 기계 장치로 이루어진 미로 구역 내부에서 깨어난다.  
미로 내부에는 회전하는 톱니바퀴와 증기 파이프 등 다양한 장애물이 존재하며, 플레이어는 마우스 클릭을 이용해 이동하고 퍼즐 요소를 해결해야 한다.  
최종적으로 구역마다 숨겨진 **열쇠(Key)**를 찾아 잠긴 문을 개방하고 미로 밖으로 탈출하면 게임을 클리어한다.

### 핵심 키워드
* **Explore**: 기계 미로 구역 탐색
* **Puzzle**: 톱니바퀴 및 장치 상호작용
* **Collect**: 열쇠 및 기계 부품 수집
* **Escape**: 문 개방 및 제한 시간 내 탈출

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 기계 미로 내부를 탐색한다.
2. 장애물과 톱니바퀴의 움직임을 파악한다.
3. 구역 내에 숨겨진 열쇠를 획득한다.
4. 출구 문 앞까지 이동한다.
5. 열쇠를 사용하여 문을 연다.
6. 제한 시간 안에 미로를 탈출하면 게임 클리어

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

미로 탐색  
↓  
장애물 및 퍼즐 직면  
↓  
경로 계산 및 이동  
↓  
아이템 / 열쇠 획득  
↓  
장치 상호작용 (문 오픈)  
↓  
다음 구역 이동  
↓  
탈출  

플레이어는 게임이 종료될 때까지 탐색 → 퍼즐 해결 → 아이템 획득 → 이동의 과정을 반복한다.

---

## 5. 플레이어 조작

| 입력 | 기능 |
| :--- | :--- |
| **Mouse Left Click** | 캐릭터 이동 / 오브젝트 상호작용 |
| **Mouse Right Click** | 카메라 회전 및 시점 조절 |
| **Space** | 특수 장치 활성화 (대시 / 기계 조작) |
| **E** | 열쇠 줍기 / 문 열기 |

---

## 6. 플레이어 기능

### 6.1 이동
플레이어는 탑다운 쿼터뷰 방식으로 미로 내부를 자유롭게 이동할 수 있다.
* **주요 기능**:
  * 마우스 클릭 지점으로 이동 (NavMesh 활용)
  * 장애물을 우회하는 경로 탐색 이동
  * 스페이스바를 활용한 긴급 회피(대시)

### 6.2 퍼즐 및 상호작용
* **주요 기능**:
  * E 키를 이용한 열쇠 및 부품 획득
  * 회전하는 톱니바퀴 타이밍에 맞춰 이동
  * 잠긴 출구 문과 상호작용하여 스테이지 클리어
